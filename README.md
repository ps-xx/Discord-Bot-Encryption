# 🛡️ Demon Network™ Encryption System

نظام تشفير المنشورات المتطور لخدمة بائعي الديسكورد، مصمم خصيصاً لسيرفر **Demon**.

## 🚀 المميزات
- واجهة مستخدم حديثة باستخدام **Components V2**.
- نظام تشفير تلقائي للكلمات الحساسة لتجنب الفلترة.
- إمكانية إرسال النص المشفر للرسائل الخاصة (DM).
- حماية ضد إعادة تشفير النصوص المشفرة مسبقاً.
